# 문서 구조와 설명 형식

이 구조는 자체 한국어 적용 패턴이다. 공식 STE나 카파시가 지정한 보고서 양식으로 인용하지 않는다. 사용자가 지정한 구조와 조직의 필수 양식을 우선한다.

## 문서 유형

| 유형 | 독자의 핵심 행동 | 기본 구성 |
|---|---|---|
| 보고서·의사결정 문서 | 근거에 따라 판단 | 결론·핵심 사항 → 근거 → 영향·위험 → 필요한 결정 |
| 기획서·제안서 | 대안을 비교하고 선택 | 목적·문제 → 제안 → 대안·근거 → 실행 조건·위험 |
| 설명·기술 문서 | 개념과 관계를 이해 | 핵심 개념 → 구성·관계 → 예시 → 한계·적용 조건 |
| 절차·업무 지침 | 정확하게 실행 | 목적·범위 → 전제조건·경고 → 담당자·단계 → 완료 기준·예외 |

결론이나 권고가 원문에 없으면 근거 없는 결론을 추가하지 않는다. 완료 기준이 없으면 확인 필요로 구분한다. 절차서를 설명문처럼 쓰거나 모든 보고서를 명령문으로 바꾸지 않는다.

존댓말, 서술형, 조직의 명사형 양식 등은 요청과 기존 문체를 따른다. 명사형 양식에서도 대상·조건·행동을 이해할 수 있어야 한다.

## 설명 형식 선택

카파시의 글 → 도표 → 웹 → 영상 제안은 형식 탐색의 방향이지 모든 작업에서 지켜야 하는 제작 순서가 아니다. 다음을 매번 판단하되 필요한 형식만 사용한다.

| 설명 대상 | 우선 고려할 형식 | 확인 사항 |
|---|---|---|
| 주장·근거·예외 | 글 | 논리 연결, 확신 수준, 출처 |
| 동일 기준의 비교 | 표 | 열의 기준, 단위, 누락값 |
| 구성 요소와 관계 | 구조도·관계도 | 연결의 종류·방향·범위 |
| 실행 순서와 분기 | 단계 목록·흐름도 | 순서, 조건, 반복, 예외 |
| 수치·추세 | 차트 | 축, 기간, 단위, 출처, 불확실성 |
| 입력값 변화에 따른 결과 | 인터랙티브 HTML | 입력 범위, 계산 근거, 출력 의미 |
| 단계적 개념·시간 변화 | 설명 영상 | 장면, 도식, 내레이션, 자막 일치 |

형식 변경은 새로운 사실을 생성하지 않는다. 그림에서 “관련”을 “원인” 화살표로 바꾸거나 미확인 연결을 확정적으로 그리지 않는다. 누락값은 0으로 채우지 않는다.

복잡한 그림에는 짧은 설명과 범례를 제공한다. 중요 정보를 색상만으로 구분하지 않는다. 이미지·영상만 있어야 이해되는 산출물에는 텍스트 설명·자막을 고려한다. 이는 자체 접근성 보완 규칙이다.

## 인터랙티브 HTML

사용자가 요청하거나 산출물 범위에 포함된 경우 제작한다. 문서만 요청했으면 무단 웹 배포·서비스 구축을 하지 않는다.

사용자의 이해 목표에 필요한 입력·단계 탐색만 구현한다. 입력값, 가정, 단위, 계산식, 출력 해석을 보이게 한다. 입력 오류를 성공처럼 처리하지 않는다. 계산 모델이 없으면 숫자와 공식을 임의로 만들지 않는다.

가능하면 일회성·자급형 산출물을 우선한다. 외부 통신·추적·의존성을 임의 추가하지 않는다. HTML 소스를 제공한 것과 브라우저에서 실행을 확인한 것을 구분한다.

## 맞춤형 설명 영상

3b1b 언급은 직관적인 도식과 단계적 개념 전개의 참고로 적용한다. 특정 창작자의 기존 대본·영상·음성·브랜드를 복제하지 않는다.

독자의 수준과 질문을 기준으로 개념 → 예시 → 변화·관계 → 결론·한계를 구성한다. 장면별 설명 목표, 화면 도식, 내레이션, 자막을 일치시킨다. 단순히 본문을 읽는 영상으로 대체하지 않는다.

음성이 필요하면 사용 가능한 합성 도구와 로컬 대안을 확인한다. ElevenLabs는 카파시가 든 예시이지 필수 의존성이 아니다. API 키를 코드·대본·로그에 넣지 않는다.

제작 도구가 없으면 대본·스토리보드 등 실제 제공 범위를 표시한다. 영상 파일 생성, 재생, 오디오·자막 동기화 확인은 각각 수행한 범위만 보고한다.

## 감독과 이해를 위한 정보

산출물에서 중요한 결론, 근거, 가정, 한계, 미확인 사항을 찾기 쉽게 한다. 숨겨진 내부 사고 과정을 출력할 필요는 없다. 사용자가 검토할 수 있는 출처와 판단 근거를 제공한다.

단순하고 명확한 문서에는 억지로 보조 산출물을 붙이지 않는다. 복잡한 설명에는 제작 가능한 형식을 고려하되 비용·보안·요청 범위를 지킨다. 일회성 설명 도구를 상시 운영 시스템으로 확장하지 않는다.
