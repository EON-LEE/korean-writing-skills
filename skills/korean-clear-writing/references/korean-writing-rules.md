# 한국어 적용 규칙

이 문서는 제공된 자료의 명확성 원칙을 한국어에 준용한 자체 규칙이다. R 번호는 이 스킬의 식별자이며 ASD 공식 규칙 번호가 아니다.

## R01. 주체와 행동

절차에는 누가 무엇을 하는지 드러낸다. 확인된 행위자를 주어 또는 단계의 담당자로 표현한다. 모두가 동일한 사용자이고 명확하면 매 문장 주어를 반복하지 않아도 된다.

“처리된다”, “반영 예정이다”만으로 책임을 숨기지 않는다. 행위자가 알려지지 않았다면 담당자 확인 필요로 표시한다. 설명문에서는 대상의 상태·현상이 초점일 때 수동 표현을 허용한다.

## R02. 하나의 독립적인 지시

문장당 독립적으로 실행·확인할 수 있는 지시 하나를 쓴다. 순서가 있으면 번호로 분리한다. 한 문장에 여러 행동을 연결하는 “하고”, “한 후”, “및”을 검토한다.

동시 실행이 필요한 행동은 한 문장에 함께 쓰고 “동시에”를 명시할 수 있다. 독립적인 순차 행동을 동시 실행으로 바꾸지 않는다. 원문의 선후·분기·반복 관계를 보존한다.

## R03. 같은 개념에는 같은 용어

문서 내부의 대표 용어와 정의를 정한다. 동의어로 보이는 용어도 지칭 대상·범위가 같은지 먼저 확인한다.

“시스템”, “플랫폼”, “서비스”가 다른 대상이면 합치지 않는다. 버튼 이름, 제품 이름, 계약상 명칭, 원문 인용은 임의로 바꾸지 않는다. 명칭이 바뀐 경우 필요한 대응 관계를 한 번 설명한다.

## R04. 같은 행동에는 같은 서술어

확인, 검토, 승인, 저장, 제출 등 업무 동사를 구분한다. 같은 단어에 여러 의미를 담거나 같은 행동을 다른 말로 부르지 않는다.

허용 의미·품사를 제한하는 영어 사전의 취지는 의미 일관성으로 적용한다. 한국어 품사를 억지로 고정하거나 영어 허용 단어 목록을 한국어 사전으로 취급하지 않는다.

## R05. 명사 연결 풀기

연속된 명사에서 대상, 목적, 소유, 적용 관계가 명확한지 검토한다. 조사와 서술어로 풀어 쓴다.

명사 연결 3단어는 원자료의 영어 기준이다. 한국어에서 3개를 넘는 개념 명사가 이어지면 검토 신호로 삼되 합성어의 음절·어절 수를 기계적으로 세어 판정하지 않는다.

공식 명칭과 고유명사는 유지하고 주변 문장에서 설명한다. 제목·표의 짧은 항목은 명사형을 허용하지만 본문과 절차까지 명사 나열로 만들지 않는다.

## R06. 시간과 상태

현재 상태, 과거 사실, 진행, 완료, 계획, 조건을 구분한다. 기준일이 제공됐으면 명시한다. 현재 날짜를 문서의 측정·집계 기준일로 임의 지정하지 않는다.

“검토를 진행하고 있는 상황이다”는 “검토 중이다”로 바꿀 수 있다. “검토 중이다”를 “검토했다”로 바꾸면 안 된다.

영어 진행형·완료형 제한은 복잡한 표현을 줄이는 취지로 준용한다. 의미에 필요한 한국어 진행·완료 표지는 유지한다. 전문 명칭 안의 영어 -ing도 임의 제거하지 않는다.

## R07. 조건 먼저, 행동 다음

원칙적으로 “조건이면, 행동한다” 순서로 쓴다. “~까지”, “~이 아니면”, “~인 경우에만”의 논리 범위와 부정을 보존한다.

필요한 경고는 해당 행동 전에 배치한다. 전제조건, 실행 중 조건, 완료 기준을 구별한다. 여러 조건의 “모두”와 “하나라도”를 바꾸지 않는다.

## R08. 세로 목록과 표

절차는 번호 목록, 독립적인 항목은 세로 목록, 동일 기준 비교는 표로 구성한다. 문장 분리로 인과관계·조건의 연결이 사라지지 않도록 필요한 연결 표현을 유지한다.

순서 없는 목록에 번호를 붙여 의도하지 않은 우선순위를 만들지 않는다. 서로 다른 기준을 같은 열에 섞지 않는다.

## R09. 전문용어와 약어

전문 명사·전문 동사는 유지한다. 독자에게 익숙하지 않은 용어는 첫 등장 시 정의하거나 짧게 설명한다. 이미 정의된 용어를 계속 풀어 써 가독성을 낮추지 않는다.

UI 명칭, 코드 식별자, 단위, 제품 버전, 약어의 표기를 보존한다. 같은 약어가 다른 의미로 사용되면 구별한다. 보편적이지 않은 약어를 새로 만들지 않는다.

## R10. 문장 길이

원자료는 영어 절차 문장 20단어, 설명 문장 25단어의 상한을 제시한다. 한국어에서는 각각 20/25어절을 넘는 문장을 우선 검토하는 신호로 사용할 수 있다. 이는 한국어 자체 검토 관행이며 공식 STE의 단어 수 판정이 아니다.

길이만 줄이지 말고 독립 행동, 주장, 조건, 삽입구를 분리한다. 이름·인용·수식·법적 조건 때문에 긴 문장은 의미를 보존한다. 예외를 둔 사실을 감사 요청 시 설명한다.

공백 기준 어절 수, 영어 단어 수, 실제 의미 단위가 다름을 명시한다. 측정하지 않은 문장 길이나 준수율을 보고하지 않는다. 검토 기준에 맞추려고 조사를 삭제하거나 단어를 붙여 쓰지 않는다.

## R11. 한 문단, 한 주제

문단마다 하나의 중심 주제를 유지한다. 설명 문단은 원칙적으로 6문장 이내로 구성한다. 주제가 바뀌면 분리한다.

문장 수를 줄이려고 세미콜론·쉼표로 여러 문장을 합치지 않는다. 인용, 필수 양식, 연결된 논증의 보존이 우선이면 예외를 설명한다. 요약만 남기고 근거를 버리지 않는다.

## R12. 조사와 문장부호

영어의 관사 등 기능어를 생략하지 말라는 원칙은 한국어의 관계 표지 보존으로 변환한다. 조사·서술어·연결 표현을 제거해 대상과 관계를 모호하게 만들지 않는다.

“및/또는”, 슬래시, 긴 괄호, 지시어를 검토한다. A와 B 모두인지 하나를 선택하는지 명확히 쓴다. “이것”, “해당”, “관련”의 지칭이 불명확하면 대상을 표현한다.

공식 표준의 세부 문장부호 규칙을 확보하지 않은 상태에서 자체 규칙을 ASD의 공식 규칙으로 인용하지 않는다.

## R13. 위험과 안전

사람의 부상 위험과 장비·데이터 등 손상 위험을 구분한다. 조직의 경고·주의 체계가 있으면 우선한다. 대상, 조건, 금지·필수 행동, 위험 결과를 알려진 범위에서 명확히 쓴다.

경고는 관련 실행 전에 둔다. 위험을 완화하거나 원문에 없는 위험을 추가하지 않는다. “식으면”의 정확한 기준이 없다고 임의 온도·시간을 지정하지 않는다. 안전상 중요한 공백은 확인 필요로 표시한다.

## R14. 사실, 추정, 권고

사실·해석·가설·계획·권고를 구분한다. 근거와 출처를 관련 주장 가까이에 둔다. 근거 없는 “대폭”, “최적”, “완벽”, “확실”을 사실로 제시하지 않는다.

효과·비교를 주장하려면 기준, 기간, 단위, 표본·범위를 유지한다. 상관을 인과로 바꾸지 않는다. 새 근거가 없으면 원문보다 확신을 높이지 않는다.

## R15. 의무와 범위

필수, 권고, 허용, 금지를 구분한다. “할 수 있다”를 “해야 한다”로 바꾸지 않는다. 적용 대상, 제외 대상, 예외, 책임, 완료 기준을 보존한다.

문장을 쉽게 만드는 것이 정책·계약·법률의 의미를 변경할 권한은 아니다. 중요한 해석이 불명확하면 확인을 요청한다.
