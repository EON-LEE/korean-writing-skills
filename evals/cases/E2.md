````markdown
# clip-tool

clip-tool은 클립보드 기록을 저장해요.

## 설치

아래 명령으로 설치 폴더에 복사합니다.

```bash
mkdir -p ~/.local/share/clip-tool
cp -R ./clip-tool/. ~/.local/share/clip-tool/
```

```powershell
New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\clip-tool" | Out-Null
Copy-Item -Recurse -Force .\clip-tool\* "$env:LOCALAPPDATA\clip-tool\"
```

같은 이름의 파일은 덮어쓰므로 설정 파일을 백업한다.

복사 후 `clip-tool --version`으로 확인하세요.
````
